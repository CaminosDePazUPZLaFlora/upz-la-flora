# Audio Files for Murals Carousel

This directory should contain audio descriptions for each mural in the carousel.

## Required Files:

- `mural1.mp3` - Audio description for "Ecos del Tiempo"
- `mural2.mp3` - Audio description for "Voces del Barrio"
- `mural3.mp3` - Audio description for "Raíces y Territorio"

## Audio Guidelines:

- Format: MP3
- Quality: Clear, professional recording
- Length: 1-3 minutes per description
- Content: Detailed description of the mural, its meaning, and artistic elements

Please add your audio files here with the corresponding names for the carousel to work properly.
